# Project instructions

Graupl Icons is part of Graupl and Accessible Ecosystem.

Read the [contribution guidelines](.github/CONTRIBUTING.md), [AI contribution policy](.github/AI_CONTRIBUTIONS.md), and [accessibility policy](.github/ACCESSIBILITY.md). Use [Unslop](skills/unslop/SKILL.md) for documentation, comments, and explanations.

Keep Sass source in `src/scss/` and public entry points in `scss/`. Preserve the Sass exports and compiled CSS paths that consumers use. Run the checks in the contribution guidelines and verify the packed package when changing its build or exports.
