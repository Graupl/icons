# Graupl Icons

Graupl Icons provides styles for icons in [Graupl](https://github.com/Graupl/graupl) and is part of [Accessible Ecosystem](https://github.com/Accessible-Ecosystem).

Install the beta with `npm install @graupl/icons@beta`. To use the Sass entry point, enable Sass's Node package importer and add:

```scss
@use "pkg:@graupl/icons";
```

The package also includes compiled CSS at `dist/css/icon.css`.

See the [contribution guidelines](.github/CONTRIBUTING.md) for build instructions.
